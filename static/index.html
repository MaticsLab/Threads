How it works

Artwork: every stroke narrower than the satin cap is stitched as a true satin column on the stroke's perpendicular; anything wider gets a tatami fill underneath. The finished file is measured — coverage, gaps, stitch lengths, hoop clearance — and rebuilt until it passes.

Lettering: text is sewn from Ink/Stitch embroidery fonts — each glyph is a hand-digitized set of satin columns and running stitches, stitched here with Ink/Stitch's rail-and-rung satin engine.

Exports go through pystitch (DST, PES, JEF, EXP, VP3, …), the previews use Ink/Stitch's realistic stitch filter with svg.panzoom.js, and the worksheet PDF follows Ink/Stitch's print template with an embTools quote sheet.
